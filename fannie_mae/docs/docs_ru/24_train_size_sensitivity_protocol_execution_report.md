# Этапы 1–4. Протокол, естественные обучающие подвыборки и обучение моделей

## Статус

Выполнены фиксация экспериментального протокола, экспорт вложенных
естественно распределённых train-подвыборок, обучение восьми моделей XGBoost
и изотоническая калибровка каждой модели. Независимая оценка на out-of-time
периоде на данном этапе намеренно не выполнялась.

## Зафиксированный контур

Эксперимент использует Q1-контур v01. Такое решение сохраняет Q3-когорты как
независимую контрольную совокупность для анализа переносимости. Train ограничен
периодом с января 2006 по декабрь 2016 года; validation с января 2017 по
декабрь 2020 года и out-of-time test с января 2021 по сентябрь 2025 года не
изменяются. Спецификация XGBoost и правило isotonic calibration закреплены до
обучения в [конфигурации](../../config/fannie_train_size_sensitivity_v01.yml).

## Правило отбора

Для каждого исхода используются все наблюдения с ненулевой шестимесячной
меткой внутри train-периода. Доля формируется детерминированным правилом
`hash(loan_identifier, monthly_reporting_period) % 10000 < threshold`; пороги
равны 100, 500, 1000 и 2500 для 1%, 5%, 10% и 25% соответственно. Подвыборки
вложены: каждая меньшая выборка полностью входит в следующую. Отбор не меняет
естественную частоту исхода.

| Исход | Доля | Наблюдения | События | Частота события, % |
|---|---:|---:|---:|---:|
| formal adverse | 1% | 622 812 | 7 527 | 1,208551 |
| formal adverse | 5% | 3 117 481 | 37 882 | 1,215148 |
| formal adverse | 10% | 6 233 999 | 75 918 | 1,217806 |
| formal adverse | 25% | 15 576 478 | 190 119 | 1,220552 |
| раннее ухудшение | 1% | 609 823 | 22 739 | 3,728787 |

Проверка показала, что все восемь файлов содержат только train-записи с
датами от 2006-01-01 до 2016-12-01; для каждой последовательности 1% → 5% →
10% → 25% число отсутствующих ключей меньшей выборки в большей равно нулю.

## Обучение и калибровка

Для каждого исхода и каждой доли обучена отдельная XGBoost-модель с заранее
зафиксированными гиперпараметрами. Затем изотонический калибратор был обучен
только на неизменной validation-выборке: 337 541 наблюдение для formal adverse
и 332 693 — для раннего ухудшения. Ни один скрипт обучения не открывал
out-of-time файл; это явно зафиксировано полем `oot_accessed: false` в каждом
из восьми манифестов.

Следующая таблица имеет диагностический характер: вероятности в её
калиброванных столбцах получены на той же validation-выборке, на которой
настраивался калибратор. Поэтому она не используется как независимая оценка
качества и не служит основанием для выбора порогов сигналов. Эти решения будут
приняты только после однократной оценки зафиксированных моделей на OOT.

В рамках этапов 1–4 не выполнялись выбор ведущего размера обучающей выборки,
подбор порогов Red/Amber или оценка метрик на OOT. Эти действия относятся к
следующему, заранее отделённому этапу.
