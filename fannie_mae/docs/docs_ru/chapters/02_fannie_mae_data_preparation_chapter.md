# Глава 2. Формирование и подготовка датасета Fannie Mae

## 2.1. Источник данных и эмпирические границы

Эмпирическую основу работы составляет Fannie Mae Single-Family Loan Performance
Primary Dataset, распространяемый через платформу Data Dynamics [57]. Набор
содержит характеристики кредита на дату выдачи и последующие ежемесячные
записи обслуживания. В анализ включены когорты выдачи `2006Q1`,
`2008Q1`, `2012Q1`, `2016Q1`, `2020Q1`, `2022Q1` и `2024Q1`. Анализ ограничен
Primary Dataset; данные HARP, multifamily и Freddie Mac не объединяются с ним,
поскольку для них необходимы самостоятельные определения и правила обработки.

Исходная популяция включает conventional, fully amortising,
full-documentation fixed-rate mortgages с первоначальным сроком не более 30
лет. Поэтому выводы относятся к данной определённой популяции и не должны
обобщаться на весь рынок ипотечного кредитования США. Семь панелей содержат
185 931 842 наблюдения «кредит–месяц» и 3 343 420 кредитов. Их покрытие и
характеристики на дату выдачи представлены в **таблицах 2.1–2.2** —
[«Покрытие когорт»](../../../reports/eda_v01/01_cohort_overview.csv) и
[«Характеристики выдачи»](../../../reports/eda_v01/03_origination_characteristics.csv),
а также на **рисунке 2.1** — [«Характеристики по когортам»](../../../reports/figures/eda_v01/03_origination_characteristics_trend.png).

## 2.2. Структура наблюдений

Единицей анализа является пара «идентификатор кредита — месяц отчётности».
Полученная продольная панель несбалансирована: различные кредиты представлены
разным числом ежемесячных наблюдений. Такая структура соответствует задаче
исследования, поскольку оценка риска обновляется по мере поступления новых
сведений об обслуживании кредита.

Первичная поставка 2008Q1 содержит 22 415 219 записей и 380 832 кредита за
период с января 2008 по март 2026 года. Внешняя проверка сортировкой не
обнаружила повторяющихся ключей «кредит–месяц». Файл не упорядочен глобально
по этому ключу; это требует явной проверки уникальности, но само по себе не
является дефектом качества данных. Наблюдения без полного будущего окна исхода
обрабатываются по правилам цензурирования, определённым в главе 3.

## 2.3. Контроль качества и воспроизводимость

Исходные поставки проверялись по числу полей, непустым идентификаторам и датам
отчётности, а также по отсутствию повторяющихся наблюдений «кредит–месяц».
Архив 2008Q1 сохранён без изменения; его SHA-256 digest равен
`6d9d3df9737fc321e70cc76bcbdf03a8bfe9ec190e472a1e1f2f9b9bd8460ae9`.
Фиксация хеш-значения позволяет однозначно идентифицировать версию источника и
воспроизвести последующие вычисления.

Официальная спецификация файла перенесена в словарь проекта. Все 113 позиций
архива имеют официальные наименования, типы и описания. В глоссарии также
указан Origination VantageScore 4.0 в позиции 114, отсутствующий в
анализируемой 113-польной поставке; это рассматривается как различие версий
формата, а не как пропущенное наблюдение.

## 2.4. Принципы подготовки

Пустые и состоящие только из пробелов значения представляются как пропуски.
Поля дат отчётности, выдачи, первого платежа и юридического погашения
преобразуются из исходного формата `MMYYYY` в календарные даты; используемые
в анализе числовые поля приводятся к числовому типу. Специальные коды
сохраняются до оценки их смысла в рамках правил построения исходов и признаков,
что исключает необоснованное перекодирование.

Очищенная запись из 113 полей и аналитическая базовая панель из 35 полей
хранятся раздельно. Zero Balance Code и Zero Balance Effective Date исключены
из признаков, поскольку могут описывать завершение кредита после даты
прогноза. Для каждого исходного поля реестр утечки информации фиксирует его
экономический смысл, временную доступность и аналитическое назначение. Такое
разделение сохраняет различие между переменными для построения исхода и
переменными, допустимыми для прогнозирования.

## 2.5. Границы подготовленной выборки

Основная выборка v01 состоит из семи Q1-когорт и не образует полной годовой
выборки. Идентификатор когорты сохраняется в последующем анализе для
прослеживаемости происхождения данных и оценки различий между vintages.

Для проверки устойчивости к кварталу выдачи обработаны девять доступных
Q3-когорт (`2006Q3`–`2024Q3` с пропусками в годах). Их суммарный объём равен
281 706 562 строкам; все архивы имеют согласованную структуру из 113 полей,
прошли первичную проверку качества и подготовлены по тем же правилам, что и
Q1-контур. Q3-набор не включается в основную обучающую выборку v01 до отдельной
оценки переносимости модели. Это сохраняет различие между разработкой модели
и независимой проверкой. См. [аудит Q3-когорт](../17_q3_archive_audit_execution_report.md)
и [сравнительный анализ](../19_q1_q3_comparative_analysis_execution_report.md).

## 2.6. Источниковая прослеживаемость

Официальный file layout и glossary используются как первичный источник для
трактовки полей, кодов и различий версий поставки [57]. Научные источники по
временной структуре кредитного риска и объяснимости не заменяют эту
спецификацию: они применяются для обоснования экспериментального дизайна,
временной валидации и требований к аудируемости модели [6], [53], [55], [56].
