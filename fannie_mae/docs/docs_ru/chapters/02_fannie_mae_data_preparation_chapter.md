# Глава 2. Формирование и подготовка датасета Fannie Mae

## 2.1. Источник данных и эмпирические границы

Эмпирическую основу составляет Fannie Mae Single-Family Loan Performance
Primary Dataset, распространяемый через платформу Data Dynamics [48]. Набор
содержит характеристики кредита на дату выдачи и последующие ежемесячные
записи обслуживания. В анализ включены когорты `2006Q1`, `2008Q1`, `2012Q1`,
`2016Q1`, `2020Q1`, `2022Q1` и `2024Q1`. Работа ограничена Primary Dataset:
данные HARP, multifamily и Freddie Mac не объединяются с ним, поскольку для
них требуются самостоятельные определения и правила обработки.

Исходная популяция состоит из conventional, fully amortising,
full-documentation fixed-rate mortgages с первоначальным сроком не более 30
лет. Следовательно, выводы относятся к этой определённой популяции и не могут
автоматически переноситься на весь рынок ипотечного кредитования США. Семь
панелей включают 185 931 842 наблюдения «кредит–месяц» и 3 343 420 кредитов.
Покрытие когорт и характеристики на дату выдачи приведены в **таблицах 2.1–2.2** —
[«Покрытие когорт»](../../../reports/eda_v01/01_cohort_overview.csv) и
[«Характеристики выдачи»](../../../reports/eda_v01/03_origination_characteristics.csv),
а также на **рисунке 2.1** — [«Характеристики по когортам»](../../../reports/figures/eda_v01/03_origination_characteristics_trend.png).

## 2.2. Структура наблюдений

Единица анализа — пара «идентификатор кредита — месяц отчётности». Продольная
панель несбалансирована: разные кредиты представлены разным числом ежемесячных
записей. Это соответствует задаче мониторинга, при которой оценка риска
обновляется по мере поступления новых сведений об обслуживании.

Первичная поставка 2008Q1 содержит 22 415 219 записей и 380 832 кредита за
период с января 2008 по март 2026 года. Проверка внешней сортировкой не
обнаружила повторяющихся ключей «кредит–месяц». Файл не упорядочен по этому
ключу глобально, поэтому уникальность проверялась явно; неупорядоченность сама
по себе не является дефектом качества. Наблюдения без полного будущего окна
исхода обрабатываются по правилам цензурирования, определённым в главе 3.

## 2.3. Контроль качества и воспроизводимость

Исходные поставки проверялись по числу полей, наличию идентификаторов и дат
отчётности, а также отсутствию повторяющихся наблюдений «кредит–месяц». Архив
2008Q1 сохранён без изменения; его SHA-256 digest равен
`6d9d3df9737fc321e70cc76bcbdf03a8bfe9ec190e472a1e1f2f9b9bd8460ae9`.
Фиксация хеш-значения идентифицирует версию источника и позволяет
воспроизвести последующие вычисления.

Официальная спецификация файла перенесена в словарь проекта. Все 113 позиций
архива имеют официальные наименования, типы и описания. В глоссарии указан
Origination VantageScore 4.0 в позиции 114, отсутствующий в анализируемой
113-польной поставке. Это различие трактуется как особенность версии формата,
а не как пропущенное наблюдение.

## 2.4. Принципы подготовки

Пустые и состоящие только из пробелов значения трактуются как пропуски. Даты
отчётности, выдачи, первого платежа и юридического погашения преобразуются из
формата `MMYYYY` в календарные даты; используемые числовые поля приводятся к
числовому типу. Специальные коды сохраняются до оценки их смысла в правилах
построения исходов и признаков, что исключает необоснованное перекодирование.

Очищенная запись из 113 полей и аналитическая базовая панель из 35 полей
хранятся раздельно. Zero Balance Code и Zero Balance Effective Date исключены
из признаков, поскольку могут описывать завершение кредита после даты
прогнозирования. Реестр утечки для каждого исходного поля фиксирует его
экономический смысл, временную доступность и аналитическое назначение. Это
разграничивает переменные для построения исхода и переменные для прогноза.

## 2.5. Границы подготовленной выборки

Основная выборка v01 включает семь Q1-когорт и не образует полной годовой
выборки. Идентификатор когорты сохраняется для прослеживаемости происхождения
данных и оценки различий между vintages.

Для проверки устойчивости к кварталу выдачи обработаны девять доступных
Q3-когорт (`2006Q3`–`2024Q3` с пропусками в годах). Их суммарный объём равен
281 706 562 строкам. Все архивы имеют согласованную структуру из 113 полей,
прошли первичную проверку качества и подготовлены по тем же правилам, что и
Q1-контур. До отдельной оценки переносимости модели Q3-набор не включается в
основную обучающую выборку v01. Это сохраняет различие между разработкой
модели и независимой проверкой. См. [аудит Q3-когорт](../17_q3_archive_audit_execution_report.md)
и [сравнительный анализ](../19_q1_q3_comparative_analysis_execution_report.md).

## 2.6. Источниковая прослеживаемость

Официальные file layout и glossary используются как первичный источник для
трактовки полей, кодов и различий версий поставки [48]. Научные источники по
временной структуре кредитного риска и объяснимости не заменяют эту
спецификацию: они обосновывают экспериментальный дизайн, временную валидацию
и требования к аудируемости модели [40], [39], [2], [46].

Полный путь данных, разграничение исследовательских и разрешённых для
прототипа слоёв, а также рабочий глоссарий сведены в [приложении Б](../appendices/appendix_b_data_lineage_and_glossary.md).
