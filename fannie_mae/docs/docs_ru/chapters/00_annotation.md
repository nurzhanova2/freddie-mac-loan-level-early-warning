# Аннотация исследования

## Тема исследования

**«Объяснимый искусственный интеллект для раннего выявления кредитного риска и
скрытого ухудшения качества заёмщика».**

## Аннотация

Работа посвящена выявлению ухудшения качества ипотечного кредита по данным,
доступным в месяце наблюдения, до наступления формального неблагоприятного
события. Эмпирическая часть основана на Fannie Mae Single-Family Loan
Performance Primary Dataset; единицей анализа является наблюдение
«кредит–месяц». Обучение, калибровка вероятностей и итоговая оценка разделены
во времени. Благодаря этому прогнозы проверяются на более позднем периоде,
который не использовался при построении модели, а признаки не содержат
будущую информацию.

Анализируются два исхода с горизонтом шесть месяцев. Formal adverse означает
появление статуса 90+ дней просрочки. Раннее ухудшение определяется как
переход из текущего состояния к просрочке 30+ дней. Логистическая регрессия
задаёт интерпретируемую базовую модель, XGBoost используется для сравнения
нелинейного прогноза. Помимо качества ранжирования оцениваются калибровка
вероятностей, пороговые правила и время опережения. TreeSHAP применяется для
описания вклада наблюдаемых признаков в прогноз, но не интерпретируется как
метод установления причинных связей.

В пределах выбранных когорт Fannie Mae XGBoost показывает более высокое
качество ранжирования на out-of-time периоде, чем логистическая регрессия.
Практический результат работы — аналитический прототип, формирующий оценку
риска, объяснение прогноза и приоритет для экспертной проверки. Прототип не
принимает автономных кредитных или надзорных решений.
