# Аннотация исследования

## Тема исследования

**«Объяснимый искусственный интеллект для раннего выявления кредитного риска и
скрытого ухудшения качества заёмщика».**

## Аннотация

Работа посвящена раннему выявлению ухудшения качества ипотечного кредита по
сведениям, доступным на дату ежемесячного наблюдения, то есть до фиксации
формального неблагоприятного события. Эмпирическая часть построена на Fannie
Mae Single-Family Loan Performance Primary Dataset; единицей анализа служит
наблюдение «кредит–месяц». Обучение, калибровка и итоговая проверка разделены
во времени. Поэтому качество прогнозов оценивается на более позднем периоде,
не использованном при построении модели, а будущая информация не включается в
признаки.

Анализируются два исхода с горизонтом шесть месяцев: formal adverse, то есть
появление статуса 90+ дней просрочки, и раннее ухудшение — переход из текущего
состояния к просрочке 30+ дней. Логистическая регрессия задаёт
интерпретируемый базовый уровень, а XGBoost представляет нелинейную модель для
сравнения. Наряду с дискриминационной способностью рассматриваются калибровка
вероятностей, пороговые правила и время опережения. TreeSHAP используется для
описания вклада наблюдаемых признаков в прогноз; его результаты не имеют
причинной интерпретации.

В пределах выбранных когорт Fannie Mae XGBoost превосходит логистическую
регрессию по качеству ранжирования на out-of-time периоде. Практическим
результатом работы является аналитический прототип, формирующий оценку риска,
объяснение прогноза и приоритет экспертной проверки. Он не заменяет кредитное
или надзорное решение и не принимает его автоматически.
