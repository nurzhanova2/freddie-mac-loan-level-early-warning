# Глава 4. Моделирование и временная валидация раннего предупреждения

## 4.1. Обоснование сравнения моделей

Эмпирическое сравнение построено вокруг логистической регрессии и XGBoost.
Логистическая регрессия задаёт прозрачный ориентир, относительно которого
можно оценить дополнительную прогностическую ценность нелинейных зависимостей;
такой benchmark-дизайн принят в исследованиях кредитного скоринга [51].
XGBoost включён как масштабируемая реализация градиентного бустинга [61], так
как связь между характеристиками кредита, состоянием платежей и последующим
ухудшением не обязана быть линейной. Более высокое качество прогноза не служит
доказательством причинной связи между признаком и исходом.

## 4.2. Дизайн временной валидации

Чтобы оценка соответствовала перспективному использованию системы раннего
предупреждения, наблюдения разделены только по календарному времени: январь
2006 — декабрь 2016 года используется для обучения, январь 2017 — декабрь
2020 года — для валидации, январь 2021 — сентябрь 2025 года — для независимой
out-of-time проверки. Сентябрь 2025 года является последним допустимым месяцем
прогноза, поскольку данные заканчиваются в марте 2026 года и требуется полное
шестимесячное окно исхода. Схема приведена на **рисунке 4.1** —
[«Хронологическое разделение»](../../../reports/figures/splits/fannie_temporal_split_timeline_v01.png).
Временное, а не случайное, разделение согласуется с подходами к динамическому
кредитному скорингу [6], [53].

Преобразования, отбор признаков, решения о выборке и калибровка оцениваются
без доступа к out-of-time периоду. Идентификатор кредита используется только
для связывания и аудита, но не включается в признаки. Поэтому повторные
ежемесячные наблюдения одного кредита соответствуют задаче динамического
мониторинга и не раскрывают модели ни идентификатор, ни значения будущих
месяцев. Состав выборки приведён в **таблице 4.1** —
[«Сводка временного разделения»](../../../reports/splits/fannie_temporal_split_v01_summary.csv).

## 4.3. Критерии оценки

ROC-AUC и PR-AUC характеризуют качество ранжирования, тогда как калибровка
показывает согласованность прогнозируемых вероятностей с наблюдаемыми
частотами. Для бинарного исхода $y_i \in \{0,1\}$ Brier score определяется как
$\operatorname{BS}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{p}_i)^2$; меньшие
значения соответствуют меньшей квадратичной ошибке вероятностного прогноза
[62].
Пороговые правила дополнительно оцениваются по precision, recall, числу ложных
сигналов и времени опережения, поскольку одного качества ранжирования
недостаточно для обоснования процедуры проверки.

## 4.4. Объём данных и фактические обучающие выборки

Расширенный контур Q1+Q3 включает 467 638 404 наблюдения «кредит–месяц» и
8 272 539 кредитов, подсчитанных по отдельным когортным панелям. Полный объём
данных используется для построения панелей, исходов, описательного анализа и
формирования детерминированных подвыборок, но не загружается целиком в память
при обучении моделей.

Для formal adverse обучающая case-control подвыборка содержит 1 262 399
наблюдений, включая 420 588 событий; validation и независимая out-of-time
выборки содержат соответственно 1 034 605 и 1 748 449 наблюдений с
естественной частотой исхода. Для раннего ухудшения соответствующие объёмы
равны 1 240 046 (396 152 события), 1 022 461 и 1 732 763 наблюдениям.
Подвыборки формируются воспроизводимым детерминированным hash-правилом;
калибровка выполняется на validation, а окончательная оценка — только на
out-of-time периоде. Раздельная оценка и калибровка вероятностей важны для
сравнения прогнозных моделей, поскольку хорошее ранжирование само по себе не
гарантирует корректность вероятностной интерпретации [63].

По отношению к полному объединённому Q1+Q3 массиву фактические обучающие
выборки составляют около 0,270% для formal adverse и 0,265% для раннего
ухудшения. Эти доли приведены только как описание соотношения объёмов, а не как
характеристика простой случайной выборки: знаменатель включает все временные
периоды полного массива, тогда как train ограничен периодом обучения. Более
того, case-control процедура намеренно повышает представительство редких
событий. Следовательно, формулировка «случайные 0,27% данных» была бы
некорректной. Выбранная схема обеспечивает вычислительную выполнимость,
воспроизводимость и достаточное число наблюдений целевых исходов; естественная
частота событий сохраняется для validation и out-of-time оценки.

## 4.5. Протокол анализа чувствительности к объёму обучения

Расширение объёма train не предполагает автоматического переобучения всех
сравниваемых алгоритмов. После выбора ведущей модели по заранее заданному
правилу — в первую очередь PR-AUC, затем Brier score и ROC-AUC на независимом
временном периоде — анализ масштаба выполняется только для этой модели и
каждого исхода отдельно. Для formal adverse исходным кандидатом является
XGBoost, показавший наилучшее сочетание указанных метрик в проведённом
сравнении.

Будущий эксперимент будет использовать несколько возрастающих
детерминированных case-control train-выборок, сформированных только внутри
периода обучения. Для всех вариантов сохраняются одинаковые временные границы,
неизменные validation и out-of-time тест; сопоставляются ROC-AUC, PR-AUC,
Brier score, precision/recall пороговых сигналов и lead time. Доля данных в
таком анализе будет рассчитываться относительно доступного train-периода, а
не относительно всех 467 638 404 наблюдений. До выполнения эксперимента эта
процедура является заранее зафиксированным планом проверки, а не эмпирическим
результатом.

## 4.6. Результаты моделирования

Логистическая регрессия достигает ROC-AUC 0,8794 для formal adverse и 0,7254
для раннего ухудшения на out-of-time выборке. Isotonic calibration снижает её
Brier score с 0,021646 до 0,004320 для formal adverse и с 0,059429 до 0,022507
для раннего ухудшения. Эти результаты задают калиброванный линейный ориентир,
а не окончательный выбор модели; они приведены в **таблицах 4.2–4.3** —
[«Логистическая базовая модель»](../../../reports/models/logistic_baseline_v01_summary.csv) и
[«Сводка калибровки»](../../../reports/models/logistic_isotonic_calibration_v01_summary.csv),
а также на **рисунке 4.2** — [«Калибровка formal adverse»](../../../reports/figures/models/formal_adverse_6m_calibration_v01.png).
Калибровка для раннего ухудшения показана на **рисунке 4.3** —
[«Калибровка раннего ухудшения»](../../../reports/figures/models/early_deterioration_6m_calibration_v01.png).

На независимом out-of-time периоде XGBoost достигает ROC-AUC 0,8943 и PR-AUC
0,2866 для formal adverse, а для раннего ухудшения — 0,7310 и 0,0663.
Сопоставление приведено в [таблице 6.1](../../../reports/models/final_model_comparison_v01.csv).
В пределах данной выборки это поддерживает выбор XGBoost как ведущей модели;
границы такого вывода рассматриваются в главе 6.
