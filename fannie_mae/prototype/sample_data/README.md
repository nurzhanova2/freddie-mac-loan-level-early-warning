# Synthetic demo data for the SupTech prototype

`suptech_alert_queue_demo.csv` is a fully synthetic interface dataset. It does
not contain Fannie Mae loan records, borrower identifiers, or production alert
decisions. It is intended only for dashboard and interaction design.

It supports the following prototype views:

- Red/Amber alert queue;
- alert details and local explanation summary;
- model/data version display;
- expert-review workflow;
- observed outcome and lead-time fields for the audit trail.

`synthetic_loan_id` must always be presented as a demonstration identifier.
